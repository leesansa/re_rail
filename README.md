# re_rail

HTML, CSS, JavaScript로 만드는 4인 웹 개발 프로젝트입니다.

## 현재 상태

프로젝트의 웹 페이지 소스는 아직 저장소에 추가되지 않았습니다. 첫 화면과 파일 구조가 정해지면 이 문서에 실행 방법과 주요 기능을 기록합니다.

## 기술 스택

- HTML
- CSS
- JavaScript

## 협업 방법

작업은 이슈로 정리하고, `main`에서 만든 작업 브랜치에서 진행합니다. 변경 사항은 PR로 제안하고 다른 팀원 한 명의 리뷰를 받은 뒤 병합합니다. 자세한 절차는 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고하세요.

## 실행 방법

실행할 웹 페이지가 추가되면 필요한 파일과 브라우저에서 여는 방법을 이곳에 안내합니다.

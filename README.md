# 프로젝트 소개 - Re:Rail

2026년 추석 당시 코레일 사이트를 통해 기차표를 예매하며, 복잡하고 직관적이지 않은 사이트 구성과 동선으로 인해 불편함을 겪었습니다.<br><br>따라서 대규모 인원이 한꺼번에 몰리는 명절이나 특수 상황에서도 사용자가 길을 잃지 않고, 몇 번의 클릭만으로 가장 빠르고 직관적으로 승차권을 예매할 수 있도록 웹 UI/UX 구조를 전면 개편(Re:Rail)하고자 하여 프로젝트를 기획하게 되었습니다.

## 팀원 및 담당 역할

- 홍순법 : 챗봇 페이지 및 마이페이지 담당
- 황건영 : 예매 시간표 및 지도 담당
- 성시원 : 메인사이트 및 예매 조회 화면 담당
- 변예담 : 메인사이트 담당

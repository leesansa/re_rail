# 지도 지역 선택 2 — 역명으로 찾기

`map-region-2.html`을 브라우저에서 열면 원본 `코레일_리디자인.fig`의 `지도_지역선택_2` 화면을 확인할 수 있습니다. 설치나 빌드는 필요하지 않습니다.

- `map-region-2.html`: 화면 구조, 검색 입력란, 역명 목록 영역
- `map-region-2.css`: 외부 CSS. 공통 설정 뒤에 헤더 → 검색창 → 조회 방식 → 역명 목록 → 작은 화면 대응 순서로 정리
- `map-region-2-data.js`: 원본 순서의 역명 36개와 버튼 크기·행 정보
- `map-region-2.js`: 역 이름·초성 검색, 목록 표시, hover와 클릭 선택 상태
- `../assets/region/list/`: 원본과 일치하는 검색·닫기 SVG, Korail M 글꼴
- `map-region-2-manifest.json`: 원본 프레임·노드, 역명·좌표·크기, 에셋 해시 기록

이미지를 새로 생성하지 않았습니다. 첫 번째 지도 화면에 사용한 SVG와 글꼴 중 두 번째 Figma 화면과 동일한 자료를 재사용했습니다. 원본 1440 × 1024 화면의 배치와 버튼 크기를 반영했습니다.

검색창에 역 이름이나 초성(예: `ㅅㅇ`)을 입력하면 목록을 즉시 필터링합니다. 역 버튼은 hover 시 파란색으로 바뀌고 클릭한 역의 선택 상태를 유지합니다. 예약 화면의 팝업에서 열었을 때는 선택한 역이 출발역 또는 도착역에 반영됩니다. `지도로 찾기` 탭은 `map-region.html`로 이동합니다. 작은 화면에서는 역명 목록을 2열로 재배치합니다. 화면 자체의 닫기 기능은 아직 연결되지 않았습니다.

예약 화면은 `Reservation/Reservation.html`에 있습니다. 이 화면을 다른 위치로 옮길 때는 `region` 폴더와 `../assets/region/`의 에셋 폴더를 함께 옮겨 주세요.
